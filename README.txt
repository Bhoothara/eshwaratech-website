HOW TO RUN IN VS CODE:
-----------------------
Step 1: Open this folder in VS Code

Step 2: Open Terminal in VS Code
        (View → Terminal)

Step 3: Install Python packages:
        pip install flask flask-cors

Step 4: Run the server:
        python app.py

Step 5: Open your browser and go to:
        http://localhost:5000
